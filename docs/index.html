Reading this page

A ranking that flips between lanes is reported as “harness-sensitive,” not averaged away. Ties are broken by process efficiency (wall-clock, then tokens, then turns) — see each task page. Harness events (malformed tool calls, parser errors, harness crashes) are never counted as model losses; a run killed by the harness is re-run once and the event stays in the report. See Calibration for the per-harness gate each model had to clear before any of these numbers count.

Every run, diff, log, transcript and calibration result on this site is published as generated — including harness re-runs. No cherry-picking. See the Method page for the full pre-registered spec.
